# Security Policy

This is a research/educational codebase — a daily market-research desk
built on public end-of-day data. It does not hold user data,
credentials or funds, it places no orders, and it is not a live
trading system.

If you find a security issue (for example a credential accidentally
committed, or a dependency vulnerability with a concrete exploit
path), please report it privately to **vrammojitbanerjee@gmail.com**
rather than opening a public issue. You should get a reply within a
few days.
